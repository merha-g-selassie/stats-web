Chapitre 24 · Inférence statistique

Comparer deux groupes

Tester si deux groupes ont la même moyenne ou la même proportion — et comment le design de l'étude change tout.

1. La question centrale

Jusqu'ici, on comparait un échantillon à une valeur fixe (H₀). Mais souvent, la vraie question est :

Est-ce que deux groupes différents ont la même moyenne (ou proportion) dans la population ?

Exemples :

  • Les femmes gagnent-elles en moyenne autant que les hommes dans cette entreprise ?
  • Le nouveau traitement réduit-il la tension artérielle plus que l'ancien ?
  • Le taux de satisfaction est-il le même entre les clients fidèles et les nouveaux clients ?

2. La distinction cruciale : indépendant ou apparié ?

Avant de choisir le test, il faut comprendre comment les données ont été collectées. Il y a deux situations très différentes :

📊 Données indépendantes

Les deux groupes sont composés de personnes différentes. Il n'y a aucun lien naturel entre un individu du groupe 1 et un du groupe 2.

Exemple : comparer les salaires de 50 femmes et 50 hommes choisis au hasard.

🔗 Données appariées

Chaque observation du groupe 1 est liée naturellement à une observation du groupe 2 — souvent, c'est le même individu mesuré deux fois.

Exemple : tension artérielle des mêmes patients, avant et après traitement.

Pourquoi cette distinction est importante : les données appariées permettent d'éliminer la variabilité entre individus. Si une personne a naturellement une forte tension, ça s'annule dans la différence avant/après. On gagne en précision — et on utilise un test différent.

3. Test t pour deux groupes indépendants

On compare les moyennes de deux groupes distincts. H₀ : les deux vraies moyennes sont égales (μ₁ = μ₂).

t = (ȳ₁ − ȳ₂) / √(s₁²/n₁ + s₂²/n₂)

En R, la syntaxe est simple : on donne les deux vecteurs de données et R fait le reste.

# Test t pour données indépendantes
t.test(salaires_femmes, salaires_hommes)

# Résultat type :
# t = -2.1, df = 96, p-value = 0.038
# 95 percent confidence interval: [-8400, -250]

L'IC donne la plage plausible pour la différence des deux moyennes. Ici, les femmes gagnent entre 250 CHF et 8 400 CHF de moins que les hommes en moyenne — et la différence est statistiquement significative.

4. Test t pour données appariées

On a mesuré le même individu deux fois (avant/après). On calcule d'abord la différence pour chaque personne, puis on teste si la moyenne de ces différences est nulle.

t = d̄ / (sᵈ / √n)

Où d̄ est la moyenne des différences individuelles et sᵈ leur écart-type.

# Test t apparié : même argument, paramètre paired = TRUE
t.test(tension_apres, tension_avant, paired = TRUE)

# Résultat :
# t = -3.8, df = 29, p-value = 0.001
# 95 percent confidence interval: [-8.1, -2.4]

Lecture : Le traitement réduit la tension artérielle de 2,4 à 8,1 mmHg en moyenne, et cette réduction est significative (p = 0,001).

5. Comparer deux proportions

Si la variable est binaire (oui/non), on compare deux proportions. H₀ : les deux vraies proportions sont égales (p₁ = p₂).

# 2 groupes : 68/120 satisfaits vs 82/150 satisfaits
prop.test(c(68, 82), c(120, 150))

# Résultat :
# X-squared = 0.98, df = 1, p-value = 0.322
# 95 percent conf. interval: [-0.08, 0.24]

Ici, p = 0,322 > 0,05 → on ne rejette pas H₀. Les deux taux de satisfaction ne sont pas significativement différents. L'IC inclut 0 (pas de différence), ce qui est cohérent.

6. Choisir le bon test

SituationVariableTest R
2 groupes indépendants, variable quantitativeMoyennet.test(grp1, grp2)
Même individu mesuré 2 foisMoyennet.test(avant, après, paired=TRUE)
2 groupes indépendants, variable binaireProportionprop.test(c(x1,x2), c(n1,n2))

7. Ce qu'il faut vérifier

  • Indépendance des observations : dans un test à deux groupes indépendants, les individus ne doivent pas se retrouver dans les deux groupes.
  • Tailles d'échantillon : les deux tests t sont robustes si n ≥ 30 dans chaque groupe (ou données normales).
  • Homogénéité des variances (optionnel) : R utilise par défaut la version de Welch, qui ne suppose pas des variances égales — c'est le choix sûr.

8. Attention à l'interprétation causale

Un test à deux groupes ne prouve pas la causalité. Si les femmes gagnent moins que les hommes, c'est peut-être lié au secteur, au poste, à l'ancienneté. Un test statistique confirme qu'il y a une différence — pas pourquoi elle existe. La causalité demande une étude expérimentale avec assignation aléatoire aux groupes.
