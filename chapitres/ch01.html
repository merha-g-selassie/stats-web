Chapitre 01 · Fondements

Définitions de base

Population, échantillon, types de variables — les briques fondamentales de toute analyse statistique.

Population vs Échantillon

La population désigne l'ensemble complet de tous les individus qu'on veut étudier. Ce terme ne se limite pas aux personnes — une population peut être des entreprises, des tweets, des villes, des transactions bancaires.

L'échantillon est un sous-groupe extrait de cette population, sur lequel on effectue les mesures concrètes. On travaille sur l'échantillon car étudier toute la population est généralement impossible : trop grand, trop coûteux, ou inaccessible.

Exemple : Tu veux savoir combien d'heures par semaine les étudiants utilisent leur smartphone. Population = tous les étudiants concernés par ton étude. Échantillon = 200 étudiants sélectionnés pour participer (n = 200).

Par convention, on utilise généralement N, μ et σ pour décrire la population, et n, x̄ et s pour décrire l'échantillon.

Deux mots utiles : un paramètre décrit une population (ex. μ, σ) ; une statistique est calculée sur un échantillon (ex. x̄, s).

Types de variables

Une variable est une propriété qui peut prendre plusieurs valeurs différentes selon les individus observés. Il y a deux grandes familles.

Variables quantitatives

On peut effectuer des opérations mathématiques dessus : addition, soustraction, calcul d'une moyenne.

Discrètes — prennent des valeurs distinctes que l'on peut compter, souvent des entiers. L'ensemble des valeurs peut être fini ou continuer 0, 1, 2, 3... sans valeur intermédiaire entre deux comptes.

Nombre d'enfants : 0, 1, 2, 3... → pas 1.7 enfant. Nombre de cours suivis par semestre.

Continues — peuvent, en théorie, prendre n'importe quelle valeur dans un intervalle. La valeur enregistrée dépend de la précision de l'instrument de mesure.

Température : 36.6°, 36.61°, 36.612°... · Taille · Durée d'une chanson.

Variables qualitatives (catégorielles)

Les valeurs sont des catégories. Elles peuvent être nominales (sans ordre) ou ordinales (avec un ordre, mais sans distance numérique définie entre les catégories).

Nominal : statut marital, nationalité, couleur préférée. · Ordinal : niveau de satisfaction, niveau de diplôme.

Cas ambigus à connaître :
• Durée d'une chanson → quantitative continue (peut être 3:42.51)
• Code postal → qualitative (1000 + 2000 n'a aucun sens géographique)
• Note sur 20 → souvent traitée comme quantitative discrète, selon le contexte
