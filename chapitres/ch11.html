Chapitre 11 · Distribution & probabilités

Probabilités

Espace des possibles, événements, addition, multiplication, indépendance et probabilité conditionnelle.

L'idée centrale

Une probabilité mesure la vraisemblance qu'un événement se produise, sur une échelle de 0 à 1.

P = 0
Impossible
P = 0.5
50 / 50
P = 1
Certain

Quand les issues possibles sont équiprobables (comme les faces d'un dé équilibré) :

P(A) = nombre de cas favorables / nombre de cas totaux possibles

Exemple : lancer un dé à 6 faces, probabilité d'obtenir un 4 ?

P(4) = 1/6 ≈ 0.167 = 16.7 %

Échelle des probabilités

P va de 0 (impossible) à 1 (certain).

Expérience aléatoire, issues et espace des possibles

Avant d'aller plus loin, il faut trois notions de base sur lesquelles reposent toutes les probabilités.

Une expérience aléatoire est une situation dont on connaît les résultats possibles, mais dont on ne peut pas savoir à l'avance lequel se produira.

  • lancer une pièce ;
  • lancer un dé ;
  • tirer une carte ;
  • observer si une personne répond « oui » ou « non » à une question.

Issue (outcome)

Une issue est un résultat individuel possible de l'expérience. Pour le lancer d'un dé à 6 faces, les issues possibles sont 1, 2, 3, 4, 5, 6. Si le dé tombe sur 4, alors 4 est l'issue observée.

Espace des possibles (Ω)

L'espace des possibles est l'ensemble de toutes les issues possibles de l'expérience. On le note Ω.

Dé à 6 faces : Ω = {1, 2, 3, 4, 5, 6}
Lancer d'une pièce : Ω = {Pile, Face}

Ω ne dit pas quel résultat va se produire — il liste tous les résultats qui pourraient se produire.

Certains manuels anglophones utilisent la lettre S à la place de Ω. Ce site utilise Ω de façon cohérente dans la suite du chapitre.

De l'expérience à l'événement

Quatre notions s'enchaînent pour arriver à une probabilité.

→
Espace des possibles Ω{1,2,3,4,5,6}
→
Issues1, 2, 3, 4, 5 ou 6
→
Événementsous-ensemble de Ω

L'espace des possibles dépend de l'expérience : si l'expérience est « lancer un dé et noter le numéro », Ω = {1, 2, 3, 4, 5, 6}. Si elle consiste seulement à noter si le résultat est pair ou impair, on peut représenter Ω = {impair, pair}. L'espace des possibles doit donc être défini avant de calculer une probabilité.

Événement

Un événement est un ensemble d'une ou plusieurs issues de l'espace des possibles : A ⊆ Ω.

Exemple avec un dé : Ω = {1, 2, 3, 4, 5, 6}. Soit l'événement A = « obtenir un nombre pair ». Alors A = {2, 4, 6}. Si le dé donne 2, 4 ou 6, l'événement A s'est produit.

Événement A = {2, 4, 6} dans Ω = {1, 2, 3, 4, 5, 6}

Les faces en couleur appartiennent à l'événement A.

Distinction à retenir :

Issue
Un seul résultat possible, ex. 4.

Événement
Un ensemble d'issues, ex. {2, 4, 6}.

Un événement peut aussi ne contenir qu'une seule issue : B = {6} représente « obtenir exactement 6 ». Un événement n'a donc pas besoin de contenir plusieurs issues.

Événement certain
P(Ω) = 1 — quelque chose dans Ω doit forcément se produire.

Événement impossible
P(∅) = 0 — ex. « obtenir 8 » avec un dé à 6 faces est impossible car 8 ∉ Ω.

Probabilité simple à partir de l'espace des possibles

Quand toutes les issues élémentaires de Ω sont équiprobables, la formule vue plus haut (cas favorables / cas totaux) s'écrit aussi :

P(A) = nombre d'issues dans A / nombre d'issues dans Ω = |A| / |Ω|

Exemple — dé équilibré : Ω = {1, 2, 3, 4, 5, 6}, A = {2, 4, 6} (nombre pair).

P(A) = 3 / 6 = 1 / 2 = 0.5 = 50 %

|A| = 3 issues favorables, |Ω| = 6 issues possibles.

Limite importante : le rapport « cas favorables / cas possibles » ne fonctionne directement que si les issues élémentaires sont équiprobables. Pour un dé équilibré, chaque face a une probabilité de 1/6, donc compter les issues fonctionne. Mais si le dé est pipé et que certaines faces sont plus probables que d'autres, compter les faces ne suffit plus : il faut alors utiliser les probabilités réellement associées à chaque issue.

Exemple — deux lancers de pièce (P = pile, F = face) : Ω = {PP, PF, FP, FF}. Soit A = « obtenir exactement une fois pile », alors A = {PF, FP}.

P(A) = 2 / 4 = 1 / 2

Chaque élément comme PF est une issue ; A regroupe deux issues différentes — cet exemple sépare bien la notion d'issue de celle d'événement.

Exemple — deux événements sur un même dé : Ω = {1, 2, 3, 4, 5, 6}, A = {2, 4, 6} (pair), B = {4, 5, 6} (supérieur ou égal à 4).

A ∩ B = {4, 6}

Cette intersection — les issues communes aux deux événements — est le point de départ des règles qui suivent.

Événements mutuellement exclusifs

Deux événements sont mutuellement exclusifs si ils ne peuvent pas se produire en même temps. Obtenir pile ou face sur un même lancer — c'est l'un ou l'autre, jamais les deux.

P(pile et face en même temps) = 0

Règle d'addition

Si mutuellement exclusifs
P(A ou B) = P(A) + P(B)

Exemple : P(1 ou 2) = 1/6 + 1/6 = 2/6 ≈ 0.33

Si NON mutuellement exclusifs
P(A ou B) = P(A) + P(B) − P(A et B)

On soustrait l'intersection pour ne pas la compter deux fois.

Mutuellement exclusifs

Pile ou face — pas de chevauchement.

Non mutuellement exclusifs

Roi ou cœur — le roi de cœur existe.

Exemple — roi ou cœur

  • P(roi) = 4/52
  • P(cœur) = 13/52
  • P(roi de cœur) = 1/52 → existe ! Donc pas mutuellement exclusifs.
P(roi ou cœur) = 4/52 + 13/52 − 1/52 = 16/52 ≈ 0.31

Sans la soustraction, on aurait compté le roi de cœur deux fois.

Règle de multiplication

La règle générale est :

P(A et B) = P(A) × P(B|A)

Si A et B sont indépendants, savoir que A s'est produit ne change pas B : P(B|A) = P(B). La formule devient alors :

P(A et B) = P(A) × P(B)

Exemple : probabilité d'obtenir pile deux fois de suite ?

P(pile et pile) = 0.5 × 0.5 = 0.25

Quand les événements sont dépendants, on garde la formule générale avec P(B|A), la « probabilité de B sachant que A s'est produit ».

Indépendants — deux lancers de pièce

Le 1er lancer n'influence pas le 2ème.

Dépendants — 2 cœurs sans remise

Le 1er tirage change les probabilités du 2ème.

Exemple — deux cœurs sans remise

  • P(1er cœur) = 13/52
  • P(2ème cœur | 1er était cœur) = 12/51 → il reste 12 cœurs sur 51 cartes
P(deux cœurs) = 13/52 × 12/51 = 156/2652 ≈ 0.059 soit environ 6 %

Probabilité conditionnelle P(B|A)

P(B|A) se lit « probabilité de B sachant que A a déjà eu lieu ». Le fait que A se soit produit change l'espace des possibilités.

P(B|A) = P(A et B) / P(A)

Exemple : probabilité qu'une personne ait suivi une formation supérieure, sachant qu'elle travaille dans le secteur tech ? On ne cherche plus parmi toute la population, mais uniquement parmi les personnes dans le tech.
