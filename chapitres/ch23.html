Chapitre 23 · Inférence statistique

Test z : comparer une proportion

Tester si une proportion observée dans un échantillon est différente d'une valeur de référence.

1. À quoi sert le test z pour une proportion ?

Parfois, la variable qu'on mesure n'est pas une moyenne, mais une proportion — une fraction de la population qui a une certaine caractéristique.

Est-ce que la vraie proportion dans la population est différente d'une valeur de référence donnée ?

Exemples :

  • Le taux de satisfaction dans une entreprise est-il différent des 75 % de l'an dernier ?
  • La proportion de fumeurs a-t-elle changé depuis les 30 % observés il y a 10 ans ?
  • Le taux de réussite à un examen est-il supérieur à 50 % ?

2. La logique du test

On note p̂ (p-chapeau) la proportion observée dans l'échantillon et p₀ la valeur de référence (H₀). La statistique z mesure l'écart entre les deux :

z = (p̂ − p₀) / √(p₀(1−p₀) / n)
  • p̂ : proportion observée dans l'échantillon
  • p₀ : proportion de référence (valeur de H₀)
  • n : taille de l'échantillon
  • Le dénominateur est l'erreur standard de la proportion sous H₀

La statistique z suit une loi normale standard (contrairement au test t). On peut donc utiliser les valeurs critiques de la loi normale : ±1,96 pour α = 0,05 bilatéral.

3. Condition d'application : le critère des 10

Avant d'utiliser ce test, vérifier :
n × p₀ ≥ 10 et n × (1 − p₀) ≥ 10

Ces conditions garantissent que l'approximation normale est valide. Si elles ne sont pas remplies (petit échantillon ou proportion très extrême), il faut utiliser un test exact de Fisher.

4. Exemple complet : taux de satisfaction

Situation : l'an dernier, 75 % des clients étaient satisfaits. On interroge 120 clients et 78 sont satisfaits, soit p̂ = 78/120 = 0,65 (65 %).

  1. H₀ : p = 0,75 (le taux n'a pas changé)
    H₁ : p ≠ 0,75 (test bilatéral)
  2. Seuil : α = 0,05
  3. Vérifier les conditions :
    n × p₀ = 120 × 0,75 = 90 ≥ 10 ✓
    n × (1−p₀) = 120 × 0,25 = 30 ≥ 10 ✓
  4. Calculer z :
    Erreur standard = √(0,75 × 0,25 / 120) = √(0,001563) ≈ 0,03952
    z = (0,65 − 0,75) / 0,03952 ≈ −2,53
  5. P-value : Pour z = −2,53 (bilatéral) → p ≈ 0,011
  6. Conclusion : p = 0,011 < α = 0,05 → on rejette H₀. Le taux de satisfaction a significativement diminué.
Distribution normale standard — z = −2,53
La statistique z = −2,53 se situe dans la queue gauche. Les zones orangées représentent les deux queues (test bilatéral).

5. En R : prop.test()

# prop.test(nb de succès, taille de l'échantillon, proportion H0)
prop.test(78, 120, p = 0.75, alternative = "two.sided")

# Résultat :
# X-squared = 6.4, df = 1, p-value = 0.011
# 95 percent confidence interval: [0.558, 0.735]
# sample estimates: p = 0.65

Note : R utilise en fait un χ² avec correction de continuité (X-squared) plutôt que z directement. Le résultat est équivalent et la logique est la même. prop.test() est la fonction standard pour ce type de test.

6. Interpréter l'IC fourni par prop.test()

L'IC à 95 % est [0,558 ; 0,735]. La valeur H₀ = 0,75 est en dehors de cet intervalle — cohérent avec le rejet de H₀.

Lecture concrète : On est à 95 % confiant que le vrai taux de satisfaction est entre 55,8 % et 73,5 %. C'est bien en dessous des 75 % de l'an dernier.

8. Ce que le résultat signifie vraiment

Attention à la direction de l'interprétation : "Le taux de satisfaction a significativement diminué" ne veut pas dire que la baisse est forcément grave. Passer de 75 % à 65 % est significatif statistiquement — mais l'important pratiquement est l'ampleur de la baisse et ce qu'elle implique pour l'entreprise. L'IC donne cette ampleur.
