Chapitre 22 · Inférence statistique

Test t : comparer une moyenne

Tester si la vraie moyenne d'une population est égale à une valeur de référence, à partir d'un seul échantillon.

1. À quoi sert le test t ?

Le test t pour une moyenne répond à une question précise :

Est-ce que la vraie moyenne de la population est différente d'une valeur de référence donnée ?

Exemples typiques :

  • La durée moyenne de livraison est-elle différente des 48h promises ?
  • La note moyenne des élèves est-elle différente de 10/20 ?
  • Le temps de travail réel est-il différent des 41h légales ?

Dans chaque cas, on a un échantillon et une valeur de référence (μ₀). Le test t mesure à quel point la moyenne observée s'éloigne de cette valeur, en tenant compte de la variabilité et de la taille de l'échantillon.

2. Comment ça fonctionne

L'idée est simple : l'écart entre la moyenne observée et la valeur de référence est-il grand par rapport à l'incertitude naturelle de l'échantillon ?

t = (ȳ − μ₀) / (s / √n)
  • ȳ : la moyenne observée dans l'échantillon
  • μ₀ : la valeur de référence (la valeur de H₀)
  • s : l'écart-type de l'échantillon
  • n : la taille de l'échantillon

Plus t est grand en valeur absolue, plus l'écart est grand par rapport à l'incertitude → p-value plus petite → plus on doute de H₀.

3. Exemple complet : les heures de travail

Situation : on enquête sur les heures de travail hebdomadaires. La loi prévoit 41h.

  1. Formuler les hypothèses :
    H₀ : la vraie moyenne est μ = 41h
    H₁ : la vraie moyenne est μ ≠ 41h (test bilatéral)
  2. Fixer le seuil : α = 0,05
  3. Données de l'échantillon :
    n = 50, ȳ = 44h, s = 6h
  4. Calculer t :
    Erreur standard = 6 / √50 ≈ 0,849
    t = (44 − 41) / 0,849 ≈ 3,54
  5. Obtenir la p-value :
    Avec t = 3,54 et df = 49 (degrés de liberté = n − 1), on obtient p ≈ 0,009
  6. Conclure :
    p = 0,009 < α = 0,05 → on rejette H₀.
    Les données fournissent des preuves significatives que la vraie moyenne est différente de 41h.
Distribution de t sous H₀ (df = 49)
La statistique t = 3,54 se situe très loin dans la queue de la distribution. La zone grisée représente la p-value (les 2 queues combinées pour le test bilatéral).

4. En R : une seule ligne

En pratique, R fait tout le calcul :

# t.test(données, valeur de référence, type de test)
t.test(heures, mu = 41, alternative = "two.sided")

# Résultat :
# t = 3.54, df = 49, p-value = 0.009
# 95 percent confidence interval: [42.29, 45.71]

Le paramètre alternative peut être "two.sided" (bilatéral), "less" (unilatéral gauche) ou "greater" (unilatéral droit).

5. Interprétation complète

Un bon compte-rendu d'un test t inclut :

  • La valeur de t et les degrés de liberté : t(49) = 3,54
  • La p-value : p = 0,009
  • L'intervalle de confiance : IC 95 % = [42,29 ; 45,71]
  • La conclusion en mots simples, avec le contexte

Conclusion rédigée : Les employés travaillent en moyenne 44h par semaine (IC 95 % : [42,3 ; 45,7]), soit significativement plus que les 41h légales, t(49) = 3,54, p = 0,009.

6. Les conditions d'application

ConditionCe qu'il faut vérifier
Données indépendantesChaque observation est un individu différent, sans lien entre eux.
Distribution approximativement normale ou n grandSi n ≥ 30, le théorème central limite garantit que la moyenne suit une distribution normale — peu importe la forme des données individuelles.
Pas de valeurs aberrantes extrêmesVérifier sur un graphique (boxplot, histogramme).

Le test t est robuste. Si n est grand (≥ 30–40), il donne de bons résultats même si les données ne sont pas parfaitement normales. En dessous de 30, il vaut mieux que les données soient assez symétriques.

7. Significatif ≠ important

Avec n = 50 000 (une grande enquête nationale), même une différence de 0,1h avec la norme légale donnerait un t gigantesque et une p-value infime. On rejetterait H₀ — mais +6 minutes par semaine n'a aucun intérêt pratique.

C'est pourquoi on rapporte toujours l'IC en plus du test : il montre l'ampleur réelle de l'effet, pas juste son existence statistique.
