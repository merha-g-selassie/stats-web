# Statistiques — Bases de statistique

A comprehensive educational resource covering statistics fundamentals, from basic definitions to correlation, inference, and linear regression.

## Overview

This project contains 19 chapters organized into four main sections:

- **Foundations**: Basic definitions, variables, data types, and frequency distributions
- **Descriptive Statistics**: Data visualization, measures of central tendency, and dispersion
- **Distributions & Probability**: Normal distribution, Z-scores, probability theory, and probability laws
- **Correlation & Inference**: Scatter plots, correlation analysis, hypothesis testing, and linear regression
